{%- comment -%} Estimated reading time in whole minutes. Usage: {% include reading-time.html content=post.content %} Code blocks are removed before counting rather than counted as prose. The word counter used to see the source text inside every fence, so a post's estimate scaled with how much YAML, shell and Mermaid it quoted rather than with how much there was to read — the Luigi post carries roughly two thousand words of configuration. Rouge wraps every fence in 
, so splitting on that is enough,
and it costs one Liquid pass over content Jekyll has already rendered.

The bibliography is dropped for the same reason, in a second pass. A CNN-series
post cites a dozen papers, and jekyll-scholar renders each one as roughly twenty
words of authors, venue and page range — so a fully cited post was picking up
about a minute and a half of "reading" nobody reads. It is a lookup table, not
prose. The 
     wrapper comes from the gem and is pinned in
the `scholar:` block of _config.yml precisely so selectors like this keep working.

220 wpm rather than the usual 250-265: what is left is still equation-heavy, and
that reads slower.
{%- endcomment -%}
